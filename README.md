# Snake Information Website 🐍

A responsive educational website developed using HTML, CSS, and JavaScript to spread awareness about snakes. The project includes information on various snake species, snake scales, first aid for snakebites, medical emergency helplines, state-wise rescue contacts, and interactive features such as search and image sliders.

## Features
- 🐍 Snake species information
- 🔍 Search functionality
- 🩹 Snakebite first aid
- 🚑 Medical emergency & helpline section
- 📍 State-wise rescue contacts
- 🖼️ Interactive image sliders
- 🎥 Video background
- 📱 Responsive design
